# shizue UI Direction

UI 작업 전에 읽는다. 제품 이름은 소문자 `shizue`, 저장소 이름은 `shizue-plot`이다.
이 문서는 이전 브랜드 가이드를 대체한다. 제품 기능과 데이터 규약은 기존 아키텍처를 따른다.

## 레퍼런스

화면의 모양은 제타(zeta-ai.io)를 따른다: 미니멀한 무채색, 테두리와 그림자를 아끼는 평평한 면, 기본은 다크.
제타의 시그니처 보라 자리에는 shizue의 민트(`#32CCBC`)를 쓴다(2026-10-17 오너 결정 — 예전의 크림·민트·잉크
시스템과 잉크 테두리·단색 그림자는 버렸다). 브랜드로는 워드마크와 토끼(아래 §자산)만 남는다.

프로모션의 확장 프로그램 기능·가격·모델 수 등의 문구는 이 제품으로 가져오지 않는다.

민트 위의 글자는 두 테마 모두 짙은 잉크색(`accent-ink`)이다. 라이트에서는 밝은 민트를 작은 글자 색으로
사용하지 않는다(링크는 `#0F766E`). 다크의 링크·포커스는 mint-2(`#90F7EC`)다. 독자의 말풍선은 다크에서 짙은
민트에 흰 글자, 라이트에서 밝은 민트에 잉크 글자다.

테마는 제타처럼 **다크가 기본**이고, OS 설정과 상관없다. 언어 선택 옆과 대화 설정 시트의 테마 선택(다크·라이트)으로
라이트를 고를 수 있고, 선택은 브라우저에 남는다(`<html data-theme="light">`). 컴포넌트는 토큰만 쓰고
테마별 클래스(`dark:`)를 두지 않는다. 라이트 값이 `@theme`이고, 다크 값은 `globals.css`가 `data-theme="light"`가
아닌 곳에서 같은 토큰에 덮어쓴다. 커스텀 UI iframe의 `color-scheme`과 기본 글자색도 현재 테마를 따른다.
창작자가 직접 지정한 색은 바꾸지 않는다.

## 서체와 레이아웃

- 워드마크(`shizue`)만 shizue.net과 같은 Bricolage Grotesque 800(`next/font`로 빌드 시 자체 호스팅)을 쓴다.
  그 밖의 글자는 모두 zeta 웹(zeta-ai.io)과 같은 Pretendard Variable, 일본어 글리프는 Pretendard JP Variable이다.
  두 서체는 npm 패키지의 dynamic subset CSS를 `globals.css`에서 불러 같은 출처에서 제공한다. 픽셀 서체는 사용하지 않는다.
- 용도별 글자 스타일은 zeta의 이름과 값을 그대로 쓰는 `globals.css`의 유틸리티다. 굵기는 600이 최대다.

| 용도 | 스타일 |
|---|---|
| 페이지 제목 | `title2 sm:title1` (24 → 28px) |
| 브랜드 화면 큰 제목 | `title24 sm:title32` |
| 섹션 제목 · 카드 섹션 · 작은 페이지 제목 | `heading1` · `heading3` · `heading2` |
| 카드 작품 이름 | `body1 font-semibold` |
| 본문 · 입력 | `text-sm` (= zeta body2, 14/20). 터치 화면(`(pointer: coarse)`)의 입력 칸(`control-box`)은 호출한 쪽이 쓴 크기와 상관없이 16px이다 — 그보다 작은 글자 입력란에 포커스가 가면 iOS가 화면을 확대한다 |
| 메타 · 라벨 · 태그 | `text-xs` (= zeta caption1, 12/16), 라벨은 `font-medium`. 대문자 변환·넓은 자간은 쓰지 않는다 |
| 아주 작은 배지 · 숫자 | `caption2` |
| 버튼 | `body14 font-medium` |
| 모바일 탭바 | `button10` |
| 대화 본문 | `.message-body` = zeta `chat` (15px / 19.2px, 자간 -0.3px), 문단 사이는 제타의 빈 줄 하나(1.2rem). 독자가 바꾸는 크기 설정은 두지 않는다 |

- 한국어는 어절 단위로 줄바꿈한다.
- 기본 간격은 4/8/12/16/24/32px. 페이지 폭은 목록 1152px, 읽기·설정 768px, 대화 화면은 제타의 헤더와 같은 1120px.
- 브랜드 화면(홈 히어로, 로그인)에는 토끼와 정원 그림만 남기고 도트 패턴은 쓰지 않는다. 채팅 본문에는 장식을 넣지 않는다.
- select는 브라우저의 화살표 대신 직접 그린 ⌄(muted)를 쓴다. ⌄는 글자가 왼쪽 테두리에서 떨어진 만큼 오른쪽 테두리에서 떨어진다(`globals.css`의 `--select-inset`, 폼 14px·우상단 언어와 테마 8px). 카드 마크업 속 select는 창작자의 것이라 그대로 둔다.
- 카드·폼은 12–24px 반경, 1px `line` 테두리 또는 면 색만. 주요 버튼은 테두리 없는 민트 면(`accent` + `accent-ink`), 보조 버튼은 `raised` 면이다. 단색 그림자와 굵은 잉크 테두리는 쓰지 않는다. 떠 있는 것(카드 hover, 메뉴)만 부드러운 `shadow-card`.
- 커버와 일러스트 썸네일은 세로 2:3이다. crack·RisuAI Realm의 카드와 같고, 가져오는 카드 이미지 대부분이
  2:3이다. 목록 그리드는 2·3·4·5열(기본·`sm`·`md`·`lg`)이고, 플롯 공개 페이지는 가로 배너 대신 제목 옆에
  포스터를 둔다. 편집기의 에셋 타일은 이미지 전체를 보여 준다(`object-contain`). 원형 아바타는 얼굴이 있는 위쪽을
  기준으로 자른다(`object-top`).
- 모바일 탭바는 아이콘과 텍스트를 함께 사용한다. 대화에서는 모든 폭에서 컴포저가 하단을, 대화의 한 줄이 상단을 차지한다(전역 헤더도 비킨다 — 아래 대화 화면). 화면 가장자리에 서는 것(탭바, 컴포저, 바텀 시트, 라이트박스)은 홈 인디케이터와 노치의 안전 영역(`env(safe-area-inset-*)`)만큼 안쪽으로 띄운다.

## 대화 화면

제타의 채팅 모양을 이 팔레트로 그린다. 값은 제타 웹의 마크업(2026-10-17 채팅방)에서 그대로 옮겼다. 한 작품의
멤버가 하나든 여럿이든 같은 모양이고, 이야기/캐릭터 구분은 화면에 없다.

- **열**: 헤더·목록·컴포저 모두 최대 1120px, 가운데. 목록의 양옆은 8px, 행 사이는 16px(제타의 행마다 `py-2`).
- **인물의 응답**: 왼쪽에 32px 원형 아바타(위쪽 기준), 6px 띄우고 그 오른쪽 위에 이름(`caption1`, 글자색 70%), 이름 아래 4px에 `bubble` 말풍선. 말풍선은 테두리가 없고, 모서리 12px에 얼굴 쪽 위 모서리만 각지다(`rounded-r-xl rounded-bl-xl`). 안쪽 여백은 12×8px, 내용 크기이며 612px을 넘지 않고, 얼굴 반대편 64px(제타의 `pr-[72px]`에서 목록 여백을 뺀 것)은 비워 둔다. 안에서 표시된 `*지문*`만 흐린 이탤릭이고 대사는 평문이다. 지문은 선택이라 대사만 든 말풍선, 지문만 든 말풍선, 둘 다 든 말풍선이 모두 있고 셋 다 같은 모양이다. 표시(`*…*`)가 없는 줄을 지문으로 짐작하지 않고, 대사의 따옴표도 떼지 않는다.
- **같은 화자가 이어지면** 이름과 얼굴을 다시 말하지 않고 열만 지킨다 — 바로 위 행이 같은 화자일 때, 그리고 한 메시지에서 상태창 뒤에 이어지는 같은 인물의 구간. 그룹 차례의 서로 다른 멤버는 같은 행 종류여도 이어지지 않는다.
- **독자의 말**: 거울 모양. 오른쪽 끝에 32px 아바타(페르소나 그림, 없으면 이름 첫 글자), 그 왼쪽에 이름(`link` 70%), 이름 아래 `bubble-user` 말풍선(왼쪽 위·아래와 오른쪽 아래가 둥근, 오른쪽 위만 각진 12px). 크기 규칙은 인물의 것과 같다. 독자의 `*…*`는 이탤릭이되 흐리지 않는다. 독자가 다른 이로 쓴 줄(`@이름:`, `@:`)은 그 인물의 말풍선·나레이션 모양으로 그 턴 안에 선다.
- **나레이션**: 제타의 나레이터 박스는 화면 배경색이라 드러나지 않는다 — 그래서 박스 없이, 그 박스의 여백(8px)만큼 들여 ≡ 표시와 흐린 글자로 전폭에 선다. 제타처럼 글 전체를 기울이지 않고, 표시된 `*…*`만 이탤릭이다. 블록 첫머리에 ≡를 한 번 두고 문단은 그 너머로 내어 쓰며, 문단 사이는 말풍선과 같이 빈 줄 하나다. 독자가 쓴 나레이션 구간도 같다.
- **장면 제목**: 나레이션과 도입부의 `#`·`##` 줄은 ≡ + 큰 굵은 글씨(`heading1`)로 흐름에 선다. 인물의 얼굴·이름 블록 밖, 열의 왼쪽 끝에서 전폭이다 — 도입부를 여는 제목은 얼굴·이름 줄 **위에** 서고, 도입부 중간의 제목 뒤에 같은 인물이 이어 말하면 이름과 얼굴을 다시 말하지 않고 열만 지킨다. 장면 제목을 따로 저장하는 데이터는 없고, 응답 속의 제목은 말풍선 안의 굵은 줄 그대로다.
- **그림**: 줄 하나를 차지한 그림은 말풍선 밖 흐름에 열 너비로, 둥근 모서리, 자기 비율 그대로 선다. 세로 그림(2:3 커버 등)이 화면을 덮지 않게 높이는 `min(70dvh, 32rem)`까지다. 문장 속 그림은 그 문장과 함께 말풍선에 남는다.
- **카드 HTML**: 상자를 짜는 마크업(상태창의 `<div>`, `<table>`, 스타일시트, 표시 스크립트가 그린 패널)은 말풍선에 넣지 않고 그림처럼 **말풍선 밖 흐름의 전폭**에 선다 — 크리에이터의 레이아웃은 크리에이터의 폭을 갖는다. 글자만 꾸미는 인라인 마크업(`<span style>`, `<font>`, `<b>`, `<br>` 등)은 그 글자와 함께 말풍선 안에 남는다. 마크업 안의 표에는 마크다운 표 스타일을 걸지 않는다.
- **모델 이름**은 응답 아래에 두지 않는다(2026-10-17). 지금 대화의 모델은 위쪽 모델 알약이 말한다.
- **기다리는 동안**: 답이 달 얼굴 옆 말풍선에서 제타처럼 점 세 개가 차례로 숨 쉰다(한 줄 높이, 모션 감소에서는 멈춘 점). 초는 세지 않고, "생각 중…"(그룹 차례에서는 "이름 입력 중…")은 스크린 리더에만 말한다. 쓰는 중에는 제타처럼 한 글자씩 붙고, 페이드도 커서도 없다. 지금 쓰는 인물의 구간은 쓴 그대로(`*…*`의 별표까지) 보이다가 그 구간이 끝나면 — 다음 인물이 시작되거나 답이 끝나면 — 한 번에 마크다운으로 그려진다.
- **AI 나레이션**은 없다(2026-10-17 소유자 결정) — 독자가 `@:`로 쓰는 나레이션과 응답 속 지문만 있다.
- **마지막 턴 아래**: 제타의 막대 — 열 오른쪽 끝에 32px 둥근 아이콘 버튼 셋(글자색 8% 테두리, 바탕 30%): 수정(연필), 요청해서 다시 쓰기(요술봉 — "어떻게 고쳐드릴까요?" 시트에 적은 말이 그 한 번의 재생성에만 쓰인다), 다시 쓰기(↻ — 그룹 차례에서는 차례 전체). 제타의 신고는 두지 않는다. 다른 답변 보기(◀ n/N ▶)는 없다 — 다시 쓴 답과 장면 편집이 대체한 버전은 서버의 트리에 남지만 화면에서는 돌아갈 수 없다.
- **메시지 동작**: 넓은 화면에서는 hover와 키보드 포커스에만 이름 옆에 나오는 조용한 글자 버튼이다. 터치 화면에는 hover가 없으므로 제타처럼 메시지를 길게(0.5초) 누르면 "메시지 메뉴" 바텀시트가 열린다 — 위에 보낸 시각, 그 아래 전폭 버튼으로 수정·복사·AI에게 숨기기·삭제. 그 행의 글은 터치로 선택되지 않는다(복사는 메뉴에 있다).
- **맨 위**: 가운데 작은 ⓘ 한 줄의 AI 고지(닫을 수 있다).
- **아래로 가기**: 독자가 위로 올라가 있을 때만, 대화 열 오른쪽 아래의 둥근 버튼(↓, 이름은 "맨 아래로"). 목록 둘레의 것이 목록의 높이를 바꾸는 것(글을 따라 커지는 입력창, 안내 줄이 서고 지는 것)은 올라간 것이 아니다 — 맨 아래를 따라가던 독자는 계속 따라가고, 마지막 줄은 입력창 위에 남는다.
- **컴포저**: 제타의 줄 — 위 경계는 옅은 선, 여백 8px, 간격 6px. 왼쪽에 32px 둥근 답변 추천 버튼(⚡, 누르면 보낼 만한 답장 세 개가 칩으로 입력창 위에 선다), 가운데 테두리 없는 `raised` 80% 입력칸(모서리 20px, 왼쪽 12px, 한 줄 35px — 위아래 8px + 1.2rem 줄, 안쪽 오른쪽에 28px `*` 지문 버튼), 오른쪽에 32px 둥근 민트 보내기(생성 중에는 멈추기 ■). 사진 첨부는 제타처럼 없다. 작성 모드 칩(대사·상황묘사·내레이터)과 다음 차례 고르기도 없다. 누구로 쓰기는 제타처럼 줄 첫머리에 치는 `@이름:`이고(내레이터는 `@:`), 줄을 연 `@` 뒤에 이름을 치는 동안 입력창 바로 위에 고르기 목록(`raised` 면, 12px 모서리, 줄마다 24px 얼굴·이름·오른쪽에 흐린 `@이름:`)이 장면에 있는 멤버와 내레이터를 친 글자로 좁혀 보인다 — ↑↓로 옮기고 Enter·Tab이나 누르기로 고르면 `@이름: `가 써지고, Esc는 다음 글자까지 목록을 접는다. 마지막 턴이 응답이면 입력창 오른쪽 위에 작은 "이어쓰기" 알약이 선다(응답 아래가 아니라 입력창 쪽, 2026-10-17 오너 결정). 아이콘 버튼의 접근 이름은 글자 버튼 시절의 단어 그대로다. 터치 화면에서는 입력란이 16px이고(iOS가 포커스 때 확대하지 않도록, 줄 높이는 그대로 1.2rem) Enter가 줄바꿈, 보내기는 버튼이다.
- **헤더**: 모든 폭에서 제타처럼 대화가 화면 하나를 통째로 쓴다 — 전역 헤더(로고·AI 연결·알림)와 탭바가 비키고, 위쪽 막대는 대화의 한 줄(52px, 좌우 10px, 아래 경계 선)뿐이다: ‹(대화 목록으로, 접근 이름 "대화 목록으로") · 캐릭터 이름(`heading3`, 작품 페이지로 가는 링크, 얼굴 없이, 먼저 말줄임으로 줄어든다) · AI 뱃지 · 메인 모델 알약(제타의 "zeta ⌄" — `raised` 면의 12px 둥근 알약, 최대 96px로 말줄임) · ☰("대화 설정"). 설정·노트·음악 음소거·테마는 모두 ☰이 여는 시트에 있다. 카드 화면이 떠 있는 동안 "카드 화면 닫기" ✕가 모델 알약의 자리를 대신한다(알약은 시트에 남는다).
- **작품 배경**(카드의 배경 HTML) 위에서는 말풍선이 불투명하므로 그대로 읽히고, 말풍선이 없는 것 — 이름, 나레이션, 장면 제목, 모델 이름, 날짜, 응답 아래 동작 줄 — 은 읽기 바탕색의 반투명 베일(블러) 위에 선다. 크리에이터가 정한 색은 바꾸지 않는다.
- **표정 화면**(RisuAI의 감정 이미지, 카드가 켠 작품에만): 멤버의 표정 그림이 `object-contain`으로 가운데에, `bubble` 면 위에 선다. 화면 모드 멤버가 여럿이면 너비를 똑같이 나눠 나란히 선다. 좁은 화면(`lg` 미만)에서는 헤더 아래·대화 열 위의 세로 띠로 뷰포트 높이의 33%이고, 아래 경계는 라인 테두리다. 오른쪽 위의 작은 둥근 셰브런(표면색 80%, 라인 테두리, 접근 이름 "표정 접기"/"표정 펼치기")이 그것을 "표정"(`caption1`, muted) 한 줄의 막대로 접고, 접힘은 그 대화에만 브라우저에 남는다. 넓은 화면(`lg` 이상)에서는 대화 열 왼쪽에 채팅 영역 너비 40%의 기둥으로 헤더 아래 전체 높이에 서고(오른쪽 경계가 라인 테두리, 접기 없음), 대화 열과 컴포저는 나머지 너비로 좁아진다. 그림이 바뀌면 200ms 크로스페이드(모션 감소에서는 바로 바뀐다). 작품 배경과 베일은 대화 열 안에서 그대로다. 메시지 안 표정 모드의 그림은 이 화면이 아니라 답장 흐름의 전폭 그림이다.

## 자산

`apps/plot/apps/web/public/brand/`:

- `mark.svg`: 레퍼런스 `src/public/icon.svg`에서 복사한 토끼 얼굴 픽셀 마크. 파비콘
  `apps/plot/apps/web/src/app/icon.svg`도 같은 파일이므로 함께 바꾼다.
- `standing.png`: 레퍼런스 `src/assets/character/standing.png`의 토끼 스프라이트. 14×17px 첫 프레임을 CSS로 정적으로 표시한다.

다크(기본)에서는 토끼를 반전한 별도 에셋을 쓰고, 라이트에서 원본을 쓴다. 토끼 옆에 다른 요소(워드마크, 정원 창)가 함께 있으므로
화면에 필터를 걸지 않고 에셋을 교체한다. `globals.css`의 `--brand-mark`·`--brand-standing`이 테마별 경로를
갖고, 마크는 `.brand-mark`, 스프라이트는 `.brand-sprite`가 배경으로 그린다.

- `standing-dark.png`: 레퍼런스가 다크에서 쓰는 결과를 굳힌 것이다. 레퍼런스는 몸통만 노란 시트
  (`standing_dark.png`)에 `invert(1) hue-rotate(180deg)`를 걸고, 그 결과 색을 `standing.png`의 픽셀에 그대로
  옮겼다. 어두운 몸통(`#151400`)에 밝은 파란 윤곽(`#9FC3FF`)이다.
- `mark-dark.svg`: 마크의 얼굴만 반전했다(흰색 → `#151400`, 스프라이트 몸통과 같은 색). 같은 필터를 그대로
  걸면 민트 윤곽이 `#007666`으로 어두워져 어두운 상단바에서 형태가 무너지므로, 민트 윤곽·눈과 분홍 귀·볼은
  그대로 둔다. `mark.svg`를 바꾸면 이 파일도 함께 바꾼다. 파비콘은 페이지가 아닌 브라우저 UI에 놓이므로 바꾸지 않는다.

로고·브랜드 장식은 개별 작품의 등장인물을 대신하지 않는다.
과거 `presence/` 이미지와 `reference/` 목업은 역사적 자료이며 현재 UI에서 참조하지 않는다.

## 상호작용과 문구

- 브랜드를 제외한 문구는 `messages/{ko,en,ja}.json`을 통한다.
- 탐색의 검색·정렬·태그는 기존 URL 상태와 뒤로 가기 동작을 유지한다.
- 로그인은 ChatGPT 한 가지이며 버튼·링크·페이지 제목은 언어별로 번역한다(한국어: `ChatGPT로 로그인`). 이메일·비밀번호·별도 가입 폼을 만들지 않는다.
- 로그인에는 Chrome 웹 스토어의 Shizue 확장(0.3.6 이상)이 필요하다. 확장이 없으면 버튼을 비활성화한 채 웹 스토어 링크와 다시 확인을 보여 준다. 로그인은 같은 탭에서 이동하며, 실패하면 로그인 화면에 번역된 오류를 보여 준다.
- 설정에서 연결된 계정과 로그아웃을 제공한다. 다시 로그인해도 작품과 대화를 유지한다.
- 빈 목록에는 관련 다음 행동을 제공한다. 로그인 후 원래 경로로 돌아가는 흐름을 유지한다.
- 비동기 생성·저장·업로드 중에는 요청에 포함된 입력과 충돌하는 전환·취소·삭제를 함께 비활성화한다. 중첩 편집기는 `fieldset disabled` 또는 `Section busy`로 묶는다.
- 실패하면 입력을 보존하고 잠금을 해제한다. 대화 응답 생성 중 다음 메시지를 미리 쓰는 입력창은 유지하되 중복 전송은 막는다.
- 버튼·링크·입력에는 키보드 포커스가 보이며, 동작 상태를 색상만으로 전달하지 않는다.
- 브랜드 장식은 `aria-hidden` 또는 빈 alt로 처리한다. 이미지 속 텍스트를 UI로 사용하지 않는다.
- 모션 감소 설정을 존중한다. 새 UI 라이브러리나 런타임 외부 폰트 요청을 추가하지 않는다.

## 이름

내부 패키지(`@shizue/*`), 카드 확장 키(`extensions.shizue`), 브라우저 저장소·이벤트·CSS 접두어(`shizue-*`,
`x-shizue-*`)와 Docker 이름은 모두 `shizue`를 쓴다. 이전 제품의 이름은 출시 전에 정리했으므로 그 이름으로
내보낸 카드나 브라우저 설정과의 호환은 두지 않는다.

OAuth 동의 화면과 콜백에 표시되는 제품 이름은 `shizue`다.
