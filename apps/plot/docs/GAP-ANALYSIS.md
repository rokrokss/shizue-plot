# 기능 갭 분석 — SHIZUE vs 제타·크랙·WHIF·Elyn (2026-08-05)

> **2026-08-05 시점의 스냅숏이다.** 경쟁사 조사 결과는 그날의 것이고, SHIZUE 열의 여러 행은 그 뒤로 실제 구현됐다
> (관계 스탯, 자동진행, 이미지 에셋, 커스텀 UI, 세계관 계층, 유저 프리셋 선택, 댓글, 재화 원장 등 — 각 행에 괄호로 표시).
> **SHIZUE의 현재 상태는 `docs/ARCHITECTURE.md`가 권위다.** 이 문서는 그때의 판단 근거를 남기기 위해 구조를 바꾸지 않았다.

SHIZUE 현재 상태 = Phase 1~3 허브까지 (커밋 `f5ecf76`). 상세 근거는 리서치 에이전트 보고서 (제타/크랙/Elyn 인벤토리, WHIF 심층) 기준. "불확실" 표기는 원 리서치의 미확정 항목.

## 2. SHIZUE가 이미 앞서는 것

1. **카드 생태계 호환** (V1/V2/V3/charx 임포트) — 4사 모두 없음. 타 플랫폼·SillyTavern/RisuAI 커뮤니티 자산 흡수 지렛대.
2. **로어북 깊이** — 정규식·데코레이터(@@depth)·재귀 스캔은 4사 어디에도 없는 파워 기능.
3. **풀 트리 브랜칭 + 리로드 안전 스와이프** — 4사 모두 슬롯/제한형.
4. **기억 구조** — 요약+벡터 하이브리드에 수동 요약 편집까지. Elyn과 유사 계열이나 벡터 검색은 우리만.
5. **필드 무제한** — Elyn과 둘뿐.
6. **다국어 3로케일 + 콘텐츠 언어 하드 파티션** — WHIF 외 유일한 구조적 글로벌 대응.

## 3. 갭 우선순위

### P0 — 서비스 성립 요건 (전원 보유, 우리 부재)
| 갭 | 비고 |
|---|---|
| 재화·과금 시스템 | 토큰 미터링은 이미 기록 중. 재화 원장·차감·충전 UI가 부재. PG 계약 전이라도 원장/차감 로직·무료 한도는 선구축 가능 |
| 세이프티·연령 게이팅 | 본인인증 계약 전이라도: 캐릭터 세이프/성인 태그, 발행 심사 파이프라인, 금칙어·모더레이션 훅, 탐색 분리 선구축 가능 |
| 크리에이터 수익 배분 | 재화 이후. Elyn 3/8%가 벤치마크. 제타의 "배분 없음"이 오히려 공급자 이탈 요인 → 우리 기회 |

|---|---|
| 이미지 에셋 시스템 ({{img::slug}}, 상황별 표시, 해금형) | Elyn 50장·WHIF 해금형·크랙 보관함 — 시각 요소의 사실상 표준. 이미지 "생성"은 제타도 축소한 영역이라 에셋 방식이 정답 |

| 출력 길이 조절 | 크랙 배수·Elyn 레벨 — 과금 결합 지점 |

### P2 — 중장기
- 커스텀 UI (Elyn JSX — 유일 기능, 파워유저 락인): 우리 계획의 Phase 4 항목과 일치. XSS 샌드박싱 설계 필요
- 세계관(스토리) 계층 (WHIF 2계층): 캐릭터 그룹·공유 로어북 — 우리 로어북 구조로 자연 확장
- 그룹챗/파티챗 (크랙 유저 멀티플레이): RisuAI PeerJS 사례 참고
- IP 라이센스 (WHIF LICENSE): 사업 개발 영역. 제타 저작권 고소 사례가 반면교사 — UGC 저작권 신고 체계 선행
- 자체/전용 모델: 제타(무료 축)·Elyn(비용 축) 모두 전략 핵심. 우리는 당분간 OpenRouter A/B로 대체
- TTS/음성: 제타 철수 사례 — 보류 타당

## 4. 시장 시사점

- **과금 스펙트럼**: 제타(광고 무료)↔크랙(전면 종량, 인상 반발)↔WHIF/Elyn(종량+무료 축). 크랙의 반복 인상 반발과 WHIF의 "웹 충전소가 앱보다 저렴" 전략 → 웹 결제 우선 + 투명한 단가가 신뢰 요소.
- **검열이 최대 이탈 트리거**: 크랙 검열봇 반발·제타 노출제한·WHIF 모델 잘림. 성인 인증 후 명확한 2-티어(세이프/언세이프)가 유저 신뢰의 표준 (WHIF/Elyn 방식).
- **저작권 리스크 현실화**: 제타 웹툰 6사 고소. 발행 심사 + 신고·테이크다운 체계는 허브 확장 전 필수.
- **여성향 버티컬의 힘**: WHIF가 좁은 타깃으로 217분/일·흑자 달성 — 범용 허브보다 버티컬 큐레이션(태그·랭킹 분리)이 유효할 수 있음.
